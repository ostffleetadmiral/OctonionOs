## Isolated quantum-behavior software probes

The added `src/quantum_model.zig` is a bounded, two-qubit Q32.32 state-vector model. It implements Hadamard and CNOT gates, norm/probability checks, and a pure-state concurrence discriminator. Fixed multiplication rounds to nearest with half ties away from zero; norm-square squares component magnitudes in checked `u128` and rounds once; integer square root rounds to nearest, ties to even. State norms accumulate in checked wider arithmetic. Gates use transactional updates, and invalid unused amplitudes are rejected. The fixed `[4]` amplitude array and two-qubit cap bound memory; scaling beyond two requires a designed new state representation rather than raising a constant. The Bell test checks the expected H+CNOT amplitudes and near-unit concurrence; a product state is the zero-concurrence control.

`src/interference.zig` defines a separate two-path model with Q32.32 amplitudes and eight local phase labels. They map to integer approximations of the eight unit-circle directions; the ±45° components use the same `SQRT_HALF` constant. Each path is rotated to complex components, summed, and intensity is the squared complex magnitude. Amplitude rotation and intensity round nearest, ties to even. Tests check in-phase reinforcement, opposite-phase cancellation, quadrature, and the full eight-step two-path fringe: relative intensities approximately `1, 0.853553, 0.5, 0.146447, 0, 0.146447, 0.5, 0.853553`, within eight Q32.32 raw units. This is a bounded discrete phase model, not general continuous phase or the donor FFT. These labels remain separate from lattice transit phase.

`src/quantum_model.zig` calculates squared-amplitude basis weights. The pure `sample` method does not mutate state; `measure` explicitly collapses an owned state. Selectors use the half-open range `[0, 2^64-1)`; the upper endpoint is rejected. `SelectorStream` and `runShots` apply a SplitMix64-style wrapping integer sequence to produce reproducible software shot counts, with per-outcome and total counts bounded by `u32`. That sequence is not physical randomness. `src/observer.zig` samples immutable snapshots, increments a local count only on successful reads, and preserves the source-state digest. `managedFlip` and explicit measurement are separately tested state-changing controls. These establish only software contracts.

These modules are computational software models. A lab-facing observer protocol still needs declared physical state variables, apparatus, operational disturbance metric, positive/null/matched-operation controls, and a predeclared threshold; no such protocol or measurement result is fabricated here.
